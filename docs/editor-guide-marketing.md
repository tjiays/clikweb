# Panduan Produk — untuk Marketing Admin

Anda mengelola **produk** di menu **Produk**. Produk tampil sebagai baris yang
bisa dibuka-tutup di halaman **Credit Scoring** dan **Business Solution**.

Hal lain yang dulu diatur Marketing — hero dan statistik halaman depan,
testimoni, timeline, logo mitra, CTA, dan teks halaman — sekarang ada di kode,
bukan di CMS. Untuk mengubahnya, hubungi developer. Lima kategori produk juga
ditetapkan di kode.

## Menambah atau mengubah produk

**Produk → Create new**

Semua kolom ada di satu halaman. Setiap tulisan muncul dua kali,
berdampingan: Bahasa Indonesia dan English.

| Kolom | Muncul di website sebagai |
| --- | --- |
| Nama produk / Product name | Judul baris. Wajib, dua bahasa. |
| Deskripsi singkat / Short description | Kalimat di bawah nama, terlihat tanpa membuka baris |
| Status | Badge berwarna di samping nama (lihat di bawah) |
| Deskripsi / Description | Bagian **Deskripsi** saat baris dibuka |
| Fitur utama / Key features | Daftar **Fitur Utama** |
| Cocok untuk / Suitable for | Daftar **Cocok Untuk** |
| Kegunaan / Use cases | Daftar **Kasus Penggunaan** |

Tiga kolom terakhir berupa daftar: tekan tambah untuk setiap butir. Butir yang
kosong tidak ditampilkan.

### Kolom kanan

| Kolom | Isi |
| --- | --- |
| Kategori | Credit Scoring, Analytics, Decisioning, Business Intelligence, atau Consulting |
| Urutan | Biarkan 0 agar produk terbaru di atas. Angka lebih kecil menyematkan ke atas. |
| Status persetujuan | Hanya dibaca. Berubah sendiri saat Anda menyimpan. |

Setelah selesai, tekan tombol oranye **Kirim untuk ditinjau**. Produk
dikirim untuk ditinjau (**In Review**) dan tayang setelah Approver menyetujui.

## Status produk

Pilih dari **Live**, **Ready to Sell**, dan **NEW**:

- **Paling banyak dua.** Memilih ketiganya ditolak dengan pesan *Maksimal
  pilih 2*.
- Boleh juga **tidak memilih sama sekali** — produk tampil tanpa badge.
- Contoh yang boleh: NEW saja; Live dan Ready to Sell; NEW dan Live.

## Dua bahasa

Produk tidak punya tombol Auto-translate. Isi versi English sendiri; keduanya
wajib diisi sebelum produk bisa disetujui. Nama produk seperti Full Report
atau CLIK SKAI Score tidak diterjemahkan.

## Perlu diingat

- Mengubah produk yang sudah tayang **tidak menurunkannya dari website**:
  versi lama tetap tayang sampai perubahan Anda disetujui.
- Tombol **Preview** membuka halaman Credit Scoring, tempat produk ditampilkan,
  untuk memeriksa hasilnya sebelum disetujui.
