## The language scheme is reversed

This is the single most important thing about this migration.

| | Old site | New site |
| --- | --- | --- |
| English | at the root — `/about-us/` | under `/en/` |

`/id/` URL redirects to an unprefixed one. Getting this backwards would
send every visitor to the wrong language.
