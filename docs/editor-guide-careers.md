# Panduan Karir — untuk HR Admin

Anda mengelola seluruh halaman **Karir**: lowongan, kategori, dan isi halaman.

## Memasang lowongan

**Karir → Lowongan Pekerjaan → Create new**

| Kolom | Isi |
| --- | --- |
| Nama posisi | Judul lowongan |
| Slug | Terisi otomatis. Muncul di alamat halaman detail. |
| Kategori | Pilih dari daftar. Tambahkan lewat menu Kategori Lowongan. |
| Key Responsibilities | Tanggung jawab utama |
| Minimum Qualifications | Kualifikasi minimum |
| Education | Pendidikan yang dibutuhkan |
| Apply email | Default `talent@cbclik.com`. Ubah bila posisi ini ditangani alamat lain. |
| Format subjek email | Muncul di bawah "Mohon cantumkan pada Subjek E-mail". |
| Lowongan masih dibuka | **Hanya lowongan yang dicentang yang tampil di website.** |

Setelah selesai, ubah **Approval Status** menjadi **In Review** dan simpan.

## Menutup lowongan

Hilangkan centang **Lowongan masih dibuka**, lalu kirim untuk review. Lowongan
akan hilang dari daftar begitu disetujui, tanpa perlu dihapus — riwayatnya
tetap tersimpan.

## Tombol Lamar

Tombol **Lamar** membuka aplikasi email pelamar dengan alamat dan subjek yang
sudah terisi. Tidak ada formulir lamaran dan tidak ada unggah berkas di
website; semua lamaran masuk lewat email.

## Isi halaman Karir

**Karir → Konten Halaman Karir**

Satu halaman berisi semuanya:

- **Hero & Banner** — judul, sub-judul, dan gambar carousel yang berganti otomatis
- **Nilai-Nilai Kami** — empat nilai perusahaan
- **Benefits** — daftar manfaat, masing-masing dengan ikon
- **Proses Rekrutmen** — lima tahap seleksi
- **Catatan kirim CV** — teks untuk kandidat yang tidak menemukan posisi yang cocok

Perubahan di sini juga melewati persetujuan Approver.

## Dua bahasa

Isi versi Indonesia, tekan **Auto-translate to English**, lalu periksa hasilnya
sebelum mengirim untuk review.
